Questions:
- Why JSON?
	We use JSON first because it is simple, visible, and teaches us how memory works. We will likely move to a database later because an intelligent system will eventually outgrow a JSON file.
- How does Python load files?
	Python
	  |
	  | 1. Find the file
	  ↓
	File location
	  |
	  | 2. Open the file
	  ↓
	File contents
	  |
	  | 3. Read the information
	  ↓
	Python memory (RAM)
- How does AI store knowledge?
	AI stores information by converting experiences, data, or knowledge into a format that a computer can save, retrieve, compare, and use later.
